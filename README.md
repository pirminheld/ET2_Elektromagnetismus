- A: Stromrichtung +1 A / 0 A / −1 A.

Der Materialordner ist `../../03_Berufsschule/ET2/00_Pirmin/Unterrichtsstunden/02_Elektromagnetismus`. Dort führt `Magnetfelder - Homepage.lnk` direkt zur Simulation; eine vorgeschaltete Übersichtsseite ist nicht erforderlich.

Das Modell verwendet B = μ₀ |I|/(2πr) für den langen geraden Leiter und B ≈ μ₀ N |I|/l für die lange Luftspule. Ohne Erdmagnetfeld/Eisenkern; Darstellung schematisch. Die Zeichnungen im Aufgabenblatt stammen aus derselben SVG-Darstellung, aber ohne Lösungspfeile, Kompassnadeln und Polbezeichnungen zum selbstständigen Ergänzen.
